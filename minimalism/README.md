# Tralance — Minimalist Landing Page

A production-ready landing page for Tralance, a freelancer income and expense tracking app.

## Stack

- React 19
- Vite 6
- CSS custom properties (no UI library)
- Inter typeface
- Lucide icons

## Getting Started

```
npm install
npm run dev
```

## Production Build

```
npm run build
npm run preview
```

## Adding the Product Screenshot

Place your screenshot at:

```
public/images/tralance-preview.png
```

The page will display the image automatically. Until the file is added, a minimal placeholder is shown.

Recommended image dimensions: **1920 × 1200** or any 16:10 aspect ratio.

## Themes

The page supports light and dark themes. The toggle is in the navigation bar. The selected theme is persisted in local storage. On the first visit, the theme matches the operating system preference.
