# Northstar Digital — Retro Design Software Services Website

A complete, responsive software services website engineered with authentic warm Retro UI design principles, inspired by vintage editorial typography, warm print color schemes, and late-20th-century craftsmanship.

## Features

- **Warm Retro Color System**: Natural parchment canvas (`#FAF6EE`), rich espresso text (`#231E1B`), warm terracotta accents (`#D9532F`), vintage golden mustard (`#C98218`), and mid-century teal (`#2A6F68`).
- **Curved Hero Lower Border**: Flowing organic divider transitioning the hero header into the capabilities grid.
- **Six Software Service Cards**: Arranged in a three-column desktop grid with custom vector illustrations, categorical tag badges, and inquiry triggers.
- **Horizontal Statistics Section**: 4 key reliability metrics with retro numerical counters.
- **Asymmetric Pricing Section**: Detailed left-column narrative with delivery guarantees, and two right-column pricing tier cards with dynamic sprint/annual billing options.
- **Spacious Editorial Footer**: Studio coordinates, directory links, newsletter subscription with live validation, and system status indicator.
- **Light & Espresso Dark Mode**: Persistent theme switching stored in localStorage.
- **Interactive Project Consultation Modal**: Complete form handling with scope selectors and confirmation state.

## Getting Started

```bash
cd RetroDesign
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
