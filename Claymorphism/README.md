# Tralance — Claymorphism Landing Page

A complete, production-ready, authentic Claymorphic landing page for **Tralance**, the income and expense tracker built for independent freelancers, contractors, and creators.

## Design Alignment

This version is designed to match the uploaded reference design structure with concise, punchy copy and authentic Claymorphic visual styling:

- **Header**: Tralance bold brand mark, clean nav links, light/dark theme switch, and coral clay `GET STARTED` pill button.
- **Hero**: Clean 2-line title (`Track Freelance Finances Simply`), short lead text (`Fast payments. Clear control.`), side-by-side App Store & Google Play black clay badges, and phone frame with screenshot plus playful curved annotation (`More Freedom Every Day`).
- **Smart Money Tools**: 4-column horizontal clay card with colorful clay icon bubbles (Send Invoices, Request Funds, Pay Bills, Mobile Tracking).
- **How It Works**: 2-column workflow with stacked angled phones, credit card plate, and 3 sequential steps with clay number bubbles.
- **Built for Everyday Finance**: 4 circular clay stat discs (`8K`, `15K`, `20K+`, `88%`) and curved annotation (`A Brighter Financial Future`).
- **Designed for Clarity**: Multi-device panoramic showcase with central app screenshot and finance preview screens.
- **What Users Say**: 3 clean clay testimonial cards with 5 stars and 1-line quotes.
- **Your Money, Anywhere**: Dark wave clay CTA card with App Store & Google Play badges, angled phone mockup, and playful annotation.
- **Footer**: Brand mark, navigation links, tagline, and copyright.

## Getting Started

### Development

```bash
cd Claymorphism
npm install
npm run dev
```

### Production Build

```bash
npm run build
```

### Linting

```bash
npm run lint
```
