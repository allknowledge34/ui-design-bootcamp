# Tralance — Flat Design Landing Page

A complete, production-ready landing page for **Tralance — Freelance Income & Expense Tracker**, designed using authentic **Flat Design** principles.

## Design Highlights

- **Pure Flat Aesthetics**: Zero drop shadows, zero gradients, zero 3D embosses, and zero glassmorphism.
- **Solid Color Foundations**: Clean black-and-white base accented by a restrained royal violet/indigo palette (`#4f46e5`).
- **Concise Copy**: Extremely short, impactful copy focusing on genuine product utility.
- **Reference Layout Structure**:
  - Split hero with clear headline (`Your Freelance Finances. Under Control.`) and clean phone frame preview.
  - Wide solid-colored feature banner with 3 core highlights.
  - Benefits and verified technical specifications section.
  - Feature showcase with clean screenshot target area.
  - Wide bold CTA banner.
- **Dual Themes**: Complete light and dark themes with persistent localStorage sync and OS preference detection.

## Running the Project

```bash
cd Flat-Design
npm install
npm run dev
```

## Build and Lint

```bash
npm run lint
npm run build
```
