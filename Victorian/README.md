# Royal Heritage — Victorian-Style Luxury Heritage Landing Page

A complete, production-ready landing page engineered with authentic Victorian UI design principles, featuring deep burgundy velvet tones, antique gold borders, engraved corner flourishes, symmetrical ornamental dividers, and elegant serif typography.

## Features

- **Victorian Color Palette**: Deep royal burgundy (`#3B0D18`), antique gold (`#C8A96E`), rich ivory paper (`#FAF7F0`), parchment tone (`#F3ECE0`), and dark walnut (`#1E130E`).
- **Ornate Ornamental Framing**: Double gold rules, corner flourishes, engraved filigree borders, and symmetrical fleur-de-lis section breaks.
- **Typography**: Inter as the readable foundation paired with Cinzel and Cormorant Garamond for regal display headlines.
- **Seven Structured Sections**:
  1. *Navigation*: Heritage crest mark, London provenance tag, and Private Viewing trigger.
  2. *Hero*: Strong serif headline ("TIMELESS ELEGANCE & NOBLE PROVENANCE"), concise description, dual CTAs, and an ornate framed vector plate.
  3. *Featured Collection*: Three authenticated historical lots (Imperial Tourbillon Chronometer, Grand Marquetry Bureau, Sovereign Sterling Tea Service) with engraved vector graphics and provenance details.
  4. *Brand Story*: Editorial panel set in deep burgundy celebrating century-old conservation ethics.
  5. *Featured Detail*: Symmetrical medallion showcase highlighting bespoke private curation services.
  6. *Final CTA*: Elegant concierge invitation to arrange gallery appointments.
  7. *Footer*: St. James's London salon address, collection directory, and royal warrant tribute.
- **Interactive Private Viewing Modal**: Accessible dialog for scheduling appointments or requesting lot provenance.

## Getting Started

```bash
cd Victorian
npm install
npm run dev
```

## Production Build

