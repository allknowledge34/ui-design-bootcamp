# Northstar Digital — Skeuomorphism Software Services Website

A complete, responsive software services website engineered with authentic modern Skeuomorphism UI design principles, featuring physical material textures, realistic depth, tactile buttons, brass rivets, and stitched borders.

## Features

- **Tangible Skeuomorphic Materials**: Warm pressed parchment desk background, tactile cardstock panels with crisp light bevels, leather and brass accent elements.
- **Physical Controls**: Tactile buttons with bevel highlights, cast drop shadows, and active inset press states.
- **Functional Light & Dark Theme**: Physical slider/rocker toggle with specular reflections and persistent state stored in localStorage.
- **Six Core Services**: Software Design, Web Development, Mobile App Development, Data Security, Digital Marketing, and Business Strategy with cohesive physical-tool SVG illustrations.
- **Horizontal Instrument Statistics**: 4 verified reliability metrics in an inset milled panel.
- **Asymmetric Pricing Section**: Complete source code guarantee seals and interactive billing mode selector (Fixed Sprint vs Annual Retainer).
- **Interactive Project Consultation Modal**: Complete form handling with scope selectors and confirmation state.
- **Spacious Editorial Footer**: Contact coordinates, directory links, newsletter subscription with live validation, and LED status diode.

## Getting Started

```bash
cd Skeuomorphism
npm install
npm run dev
```

## Production Build

