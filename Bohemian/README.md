# Soulful Living — Bohemian Lifestyle & Home Decor Landing Page

A complete, production-ready landing page engineered with authentic Bohemian UI design principles, featuring an earthy color palette (terracotta, warm cream, sand, muted olive, rust), organic arch shapes, botanical line art, relaxed editorial layouts, and warm typography.

## Features

- **Bohemian Color Palette**: Terracotta (`#C86D51`), rust (`#9E472A`), sunlit ochre (`#D99B4B`), olive green (`#687050`), warm cream (`#FAF6EE`), sand (`#F2EADB`), and walnut brown (`#3A2B24`).
- **Organic Architectural Shapes**: Gentle curves, terracotta arch cutouts, and hand-drawn botanical silhouettes.
- **Typography**: Inter as the clean, highly-readable foundation paired with Fraunces for warm expressive display titles.
- **Seven Structured Sections**:
  1. *Navigation*: SOULFUL LIVING brand mark, links, shop action, and interactive basket indicator.
  2. *Hero*: High-impact headline ("HANDMADE FOR A BRIGHTER EVERYDAY"), natural subtext, dual CTAs, and an organic terracotta arch stage.
  3. *Featured Collection*: Three distinct categories (Handcrafted Ceramics, Woven Natural Fibers, Botanical Accents) with price tags and "ADD TO BASKET" actions.
  4. *Brand Story*: Editorial panel celebrating unhurried craftsmanship, natural vegetable dyes, and zero synthetic shortcuts.
  5. *Lifestyle Showcase*: Image-free composition with overlapping clay arch graphics and slow living narrative.
  6. *Final CTA*: Concise dispatch subscription form with instant confirmation.
  7. *Footer*: Ojai Valley and Byron Bay studio coordinates, directory links, and ethical artisan trade guarantee.
- **Basket Drawer**: Functional slide-over drawer displaying added items, live subtotal, quantity count, item removal, and dispatch confirmation.

