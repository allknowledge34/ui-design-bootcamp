# FORM & FABLE — Vector Art Landing Page

An independent creative studio website built with authentic Vector Art aesthetic, crisp geometric silhouettes, and deliberate color blocking.

## Design Highlights

- **Aesthetic**: Authentic Vector Art direction featuring pure Euclidean geometry, smooth Bézier curves, and high-contrast color blocking.
- **Palette**: Cobalt Blue (`#1E3BB3`), Coral (`#FA5246`), Warm Yellow (`#FFC226`), Mint Green (`#2EC4B6`), Off-White Paper (`#FAF8F5`), and Deep Ink Black (`#121620`).
- **Typography**: Inter with geometric bold tracking and deliberate hierarchy.
- **Original Vector Artworks**:
  - The Creative Engine (Hero SVG canvas)
  - Apothecary Botanical Geometry (Aetheria Botanicals)
  - Stepped Monolithic Cityscape (The Monolith Review)
  - Velocity Aerodynamic Flow (Tempo Electric)
  - The Anatomy of a Vector (Studio Ethos exploded diagram)
  - Four distinct service spot vector glyphs
- **Interactive Features**:
  - Full-fidelity Case Study modal with strategic impact analysis and color swatches
  - Dynamic Project Scope & Palette Configurator
  - Client Inquiry drawer with pre-fill parameters and live feedback
  - Studio Dispatch quarterly subscription with toast validation
  - Responsive navigation with mobile menu drawer

## Technology Stack

- React 19
- Vite 6
- Plain CSS (Zero UI frameworks)
- Semantic HTML5

## Running Locally

```bash
cd VectorArt
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
