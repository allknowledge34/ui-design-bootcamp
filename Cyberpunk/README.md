# KROM//LABS — Cyberpunk Digital Services Landing Page

A complete, production-ready digital services landing page engineered with authentic Cyberpunk UI design principles, featuring dark charcoal surfaces, neon cyan and magenta accents, chamfered corner geometry, and an interactive HUD terminal.

## Architecture

- **Navbar**: Brand HUD mark, anchor links (Services, Work, About, Contact), and Initiate Uplink action.
- **Hero**: High-contrast headline, one-sentence description, dual actions, and simulated real-time terminal telemetry monitor.
- **Services**: Three carefully designed cyber capability cards:
  - 01 // Cybernetic Systems & Architecture
  - 02 // Neural UI & Product Engineering
  - 03 // Offensive Security & Hardening
- **Selected Work**: Three detailed project previews (NEURA//VAULT HSM, AEON//CORE Trading Engine, CYBER//GRID Spatial Mesh) with vector schematics and stack badges.
- **About / Stats**: Four sharp telemetry metrics (99.999% availability, <12ms latency, 240+ deployed systems, 0 breaches).
- **Contact CTA**: Interactive console transmission form with email validation, GPG key ID, and confirmation state.
- **Footer**: Grid telemetry beacon, navigation, and legal status.
- **Uplink Modal**: Accessible popup dialog with full form handling and transmission handshake.
