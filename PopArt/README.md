# POP STORE — Pop Art Streetwear & Culture Landing Page

A complete, production-ready landing page engineered with authentic Pop Art design principles, inspired by comic book printing, Ben-Day halftone patterns, heavy black outlines, starburst badges, and screaming primary colors.

## Features

- **Comic Pop Visual Language**: Bold primary palette (canary yellow, pop red, cyan, magenta, black), Ben-Day halftone dot backgrounds, hard black box shadows (`5px 5px 0 #000`), and speech bubbles.
- **Typography**: Inter as primary font with heavy 900 weight, paired with Bangers display font for high-impact comic headlines and text shadow layers.
- **Navigation**: POP STORE wordmark, anchor links, shop CTA button, and interactive cart badge counter.
- **Hero Spread**: High-impact "GOOD VIBES ONLY!" headline with Pop Art text shadow layers, short supporting description, dual CTAs, and a comic graphic stage with speech bubbles and starburst stickers.
- **Featured Collection**: Four distinct streetwear drops with custom flat vector illustrations, tags, prices, and an interactive "ADD TO BAG" action.
- **Brand Manifesto**: Contrasting hot pink halftone panel with the core brand statement: "WE DON'T DO SUBTLE. WE PAINT THE CITY IN SCREAMING COLOR."
- **Final Promotional CTA**: VIP Pop Club early access form with input validation and instant code grant.
- **Cart Drawer**: Functional slide-over cart drawer with quantity counts, live subtotal, item removal, and checkout confirmation.
- **Footer**: Brand background, studio dispatch info, and raw pigment guarantee stamp.

## Getting Started

```bash
cd PopArt
npm install
npm run dev
```

## Production Build

