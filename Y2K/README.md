# Tralance — Y2K / Retro-Futurism Design Landing Page

A complete, production-ready landing page for **Tralance — Freelance Income & Expense Tracker**, designed using modern **Y2K / Retro-Futurism UI** principles inspired by the provided art direction.

## Design Highlights

- **Clean, Human-Designed Composition**: Generous whitespace, focused copy, and clear visual hierarchy without AI-like visual clutter.
- **Y2K Retro-Futurism Accents**: 4-point starburst motifs (✦), sunburst/orbit ring backdrops, electric pastels (Yellow, Cyber Purple, Soft Pink), and black pill capsule buttons.
- **Hero Split**: Clear 2-column layout with bold headline, Google Play / APK store capsules, and a phone frame with live runway status.
- **Sleek Benchmark Card**: 5-star rating cards highlighting 100% Local Storage, 0 Logins, and Native Android.
- **3-Card Feature Showcase**: Colorful pastel cards with circular icon badges and clean pill buttons.
- **Dual Themes**: Complete light and dark themes with persistent localStorage sync and OS preference detection.

## Running the Project

```bash
cd Y2K
npm install
npm run dev
```

## Build and Lint

```bash
npm run lint
npm run build
```
