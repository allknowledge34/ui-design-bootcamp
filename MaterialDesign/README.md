# Northstar Digital — Material Design Services Website

A complete, production-ready software agency website for **Northstar Digital**, designed using authentic **Material Design** principles and directly aligned with the provided reference art direction.

## Design Highlights

- **Material Surfaces & Elevation**: Soft, realistic card shadows, rounded surface corners (`border-radius: 24px`), and subtle interactive micro-elevation on hover.
- **Reference Layout Structure**:
  - Slim top navigation with brand mark, links, and action button.
  - Centered introduction banner with a soft pastel gradient background and curved bottom edge.
  - Six service cards arranged in a 3-column desktop grid, each featuring custom vector illustrations and circular purple action buttons.
  - Horizontal statistics strip (`482+ Projects Done`, `98% Success Rate`, `234+ Winning Awards`, `72K Happy Clients`).
  - Asymmetric pricing section with a 2-column card layout.
  - Spacious curved footer with contact details, navigation links, and newsletter subscription form.
- **Dual Themes**: Complete light and dark themes with persistent localStorage sync and OS preference detection.

## Running the Project

```bash
cd MaterialDesign

npm run dev
```
