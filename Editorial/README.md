# Verve Atelier — Editorial Digital Services Landing Page

A complete, production-ready digital services landing page engineered with authentic Editorial UI design principles, featuring typography-led layouts, large expressive headlines, asymmetric compositions, warm off-white book paper palette, vermilion accents, and hairline divider rules.

## Design Highlights

- **Typography-Led Masthead**: Oversized Inter display headlines with Instrument Serif italic editorial accents.
- **Folio & Broadsheet Hierarchy**: Thin hairline divider lines, roman numeral indices, and small uppercase metadata stamps.
- **Asymmetric Layouts**: Inspired by high-end architectural magazines and modernist print spreads.
- **Three Focused Service Offerings**: Broadsheet layout displaying Digital Systems, Web Platforms, and Brand Identity without repetitive generic cards.
- **Art-Directed Archival Folio**: Thoughtful image areas with graceful vector fallbacks and compact typographic captions.
- **Operating Standards & Philosophy**: Genuine editorial essay, manifesto pull quote, and studio principles.
- **Editorial Transmission Form**: Validated commission inquiry form with live acknowledgment and accessible modal console.

## Getting Started

```bash
cd Editorial
npm install
npm run dev
```
